Privacy Policy

Effective date: October 3, 2026 · Operator: WIM Co. Ltd. (The AI Cycle Operations Team)

This Privacy Policy explains how The AI Cycle system (the "API Client") and this website handle information.

1. Use of YouTube API Services

The API Client uses YouTube API Services. By using YouTube API Services through the API Client, information is also handled under the Google Privacy Policy: http://www.google.com/policies/privacy.

2. Who uses the API Client

The API Client is an internal tool. It is used only by members of the operating team, who sign in with the Google account that owns our YouTube channel. It is not offered to the public and does not accept sign-ins from other users.

3. Information we access, collect and store

  • OAuth credentials for our own Google account (access and refresh tokens), stored on the operator's computer.
  • Channel information for our own channel: channel ID, title and public statistics.
  • Video information for our own videos: video IDs, titles, descriptions, tags, publish times and public statistics (view, like and comment counts).
  • YouTube Analytics reports for our own channel and videos: aggregated metrics such as views, engaged views, watch time, average view duration, average view percentage, likes, comments, shares and subscribers gained or lost.

We do not collect personal information about viewers. YouTube Analytics data is aggregated and does not identify individual viewers. We do not currently collect the text of comments; if this changes, we will update this policy first.

4. How we use the information

The information is used only to operate and improve our own channel: to publish our videos, to measure how each video performed, and to let the system learn which approaches work better for future videos.

5. How we share the information

  • We do not sell, rent or share the information with third parties for their own purposes.
  • Aggregated performance metrics and planning notes about our own videos (which contain no personal information about viewers) may be processed by third-party AI service providers, such as large language model APIs, solely to generate analysis and plans for our channel.
  • We may disclose information if required by law.

6. Data storage, retention and deletion

  • Data is stored on the operator's computer and in private storage accessible only to the operating team.
  • Data obtained from the YouTube Analytics API is kept for as long as necessary for this project while our authorization remains active. We confirm at least every 30 days that the authorization is still valid.
  • Other data obtained from YouTube API Services (for example, public statistics from the YouTube Data API) is deleted or refreshed within 30 days.
  • If authorization is revoked, we delete all data obtained through YouTube API Services within 7 days. Deletion requests sent to us are handled within 7 days.

7. Third-party content and advertising

The API Client does not serve advertisements and does not allow third parties to serve content or advertisements through it. This website does not display advertisements.

8. Information stored on devices and cookies

The API Client stores OAuth credentials and data files on the operator's computer. This website does not use cookies, analytics or tracking tools. The website is hosted on GitHub Pages, and GitHub may collect technical information such as IP addresses when the site is accessed, as described in the GitHub Privacy Statement.

9. Revoking access

Access granted to the API Client can be revoked at any time from the Google security settings page: https://security.google.com/settings/security/permissions.

APIクライアントは社内ツールであり、運営チームが自社チャンネルを所有するGoogleアカウントでのみ使用します。一般には提供していません。

自社アカウントのOAuth認証情報、自社チャンネルの情報、自社動画の情報と公開統計、自社チャンネルのYouTubeアナリティクス集計値（再生数、エンゲージビュー、総再生時間、平均視聴時間、平均視聴率、高評価数、コメント数、共有数、登録者の増減）を取得します。視聴者個人の情報は取得しません。コメント本文は現在取得していません。

第三者への販売・貸与・提供は行いません。ただし、自社動画の集計値と企画メモ（視聴者の個人情報を含まない）を、分析と企画作成のためにAIサービス提供事業者（大規模言語モデルのAPI等）で処理することがあります。法令に基づく場合は開示することがあります。

6. 保存期間と削除

データは運営者のPCおよび運営チームのみが利用できる非公開の保存先に保管します。YouTubeアナリティクスAPIのデータは認可が有効な間、必要な期間保存し、30日ごとに認可の有効性を確認します。その他のAPIデータは30日以内に削除または更新します。認可が取り消された場合は7日以内に全データを削除します。削除の依頼も7日以内に対応します。

APIクライアントは広告を配信せず、第三者によるコンテンツや広告の配信も行いません。本サイトにも広告はありません。

8. 端末への保存とCookie

APIクライアントは運営者のPCに認証情報とデータを保存します。本サイトはCookieや解析ツールを使用しません。本サイトはGitHub Pagesで公開しており、GitHubがIPアドレス等の技術情報を取得する場合があります。

9. アクセス権の取り消し

Googleのセキュリティ設定ページ（https://security.google.com/settings/security/permissions）からいつでも取り消せます。
